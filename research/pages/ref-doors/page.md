# Door list

This reference page lists every door that the game's level scripts place: 484 doors in 46 scripts on the PS2 disc.
Every value was read from the PS2 disc (NTSC-U, `SLUS_212.15`), from the compiled Lua 4.0 scripts inside
`WARRIORS.WAD`, located through `WARRIORS.DIR`. The door types, their kinds and the door commands are on the page
`doors`; the level records are on `ref-levels`.

## Disc sources

| Source | Directory entry (zero-based) | Size in bytes | Values taken from it |
| --- | ---: | ---: | --- |
| `level<N>.lua` | 45 scripts | various | One placement per door: type, position, rotation, triangles, number, key |
| `level86_chapter1_reg.lua` | 9,162 | 23,860 | One more placement for `level86` |
| `config_preload3.lua` | 3,772 | 308,938 | The object record of each placed type (all 36 have one) |

## Columns

| Column | Meaning |
| --- | --- |
| No. | The door's number, the fifth placement value; 1 to N within each level script |
| Type | The door type name without its common prefix `dyn_door_`; `cabin_a` stands for `dyn_door_cabin_a` |
| Key | The name under which the script keeps the door's handle |
| Position | x, y, z as stored; z is height |
| Rotation | The third and fourth of the four stored rotation numbers; the first two are 0 for every door |
| Triangles | The two collision triangle numbers, always n and n + 1 |

Rows are sorted by door number. Numbers are written as stored, rounded to six decimals; `1e-06` is 0.000001.
